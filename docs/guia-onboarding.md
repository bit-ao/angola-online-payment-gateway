# Guia de Onboarding (Geral)
1) **Contacto comercial** → proposta, contrato, NIF, IBAN, docs societários.  
2) **KYC/AML** → validações previstas pela lei e pelo fornecedor.  
3) **Sandbox** → credenciais de teste, geração de referências/casos de erro.  
4) **Integração técnica** → endpoints, webhooks, assinatura, idempotência.  
5) **Homologação** → transações de teste e auditorias.  
6) **Produção** → credenciais finais, monitorização, planos de contingência.  
7) **Conciliação** → extratos, ficheiros de liquidação, tarifas e impostos.
