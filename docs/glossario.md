# Glossário (curto)
- **KYC/AML**: Conhece o Cliente / Anti-Branqueamento de Capitais.  
- **Settlement/Liquidação**: Transferência de fundos do fornecedor para o comerciante.  
- **Webhook**: Notificação de evento assíncrona enviada pelo fornecedor para o teu sistema.  
- **Idempotência**: Mesma requisição repetida → mesmo efeito, sem duplicar transações.
