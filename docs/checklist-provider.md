# Checklist por Fornecedor
- [ ] Links oficiais (site, docs, portal do comerciante)
- [ ] Canais suportados (referência, POS/TPA, e-commerce, mobile money, QR)
- [ ] Processo de onboarding (contrato, KYC/AML, testes, produção)
- [ ] Detalhes técnicos (autenticação, webhooks, sandbox, SDKs)
- [ ] Moedas e liquidação (prazo, tipo, conciliação)
- [ ] Custos (fixo, %), se públicos
- [ ] Compliance (PCI DSS/SAQ, políticas de risco e fraude)
- [ ] Contactos de suporte/parcerias
- [ ] Estado da informação (parcial/confirmada/obsoleta) + fontes
